# Speech Handoff

Last updated: 2026-09-01

## Current Goal

Keep the English 512D pipeline and the Mandarin side path separate.
The Mandarin pipeline now has its own preprocessing, HDF5 output, dual-stream training, best-checkpoint selection, and eval CSV export.

## Repo Map

- Repo root: `Speech/`
- English 512D data: `data/hdf5_data_512/`
- English trained model output: `model_training/trained_models/baseline_rnn_512/`
- Mandarin raw source: `sub-01/speech/`
- Mandarin generated HDF5: `data/hdf5_chinese/`
- Mandarin training outputs: `chinese_speech/trained_models/`

## English 512D

Use the existing 512D English pipeline only.

Train:

```bash
cd ~/nejm-brain-to-text_self/model_training
python train_model.py rnn_args.yaml
```

Eval without LM:

```bash
cd ~/nejm-brain-to-text_self/model_training
python evaluate_model.py --model_path trained_models/baseline_rnn_512 --data_dir ../data/hdf5_data_512 --eval_type test --gpu_number 0 --skip_lm
```

Eval with LM:

```bash
cd ~/nejm-brain-to-text_self/model_training
python evaluate_model.py --model_path trained_models/baseline_rnn_512 --data_dir ../data/hdf5_data_512 --eval_type test --gpu_number 0
```

Important:

- `--model_path` must point to the training output directory, not `data/`.
- The pretrained checkpoint layout is expected as `model_path/checkpoint/args.yaml` and `model_path/checkpoint/best_checkpoint`.

## Mandarin Side Path

This is independent from the English pipeline.

### Builder

- Source: `sub-01/speech/`
- Output: `data/hdf5_chinese/`
- Output files per session:
  - `data_train.hdf5`
  - `data_val.hdf5`
  - `data_test.hdf5`
  - `trial_manifest.csv`
  - `metadata.json`

Current Mandarin preprocessing facts:

- Sentence-only sessions are used by default.
- Single-character diagnostic trials are excluded by default.
- Blank/no-action trials are excluded by default.
- z-score is fixed per day from the first 20 included trials for that day.
- The same fixed mean/std is used for train/val/test on that day.
- Training HDF5 stays `T x 256`.
- Training uses the independent dual-stream syllable/tone decoder.

Builder command:

```bash
cd ~/nejm-brain-to-text_self
python -m chinese_speech.builder --output-root data/hdf5_chinese --overwrite
```

### Training

Config:

- `chinese_speech/train_config.yaml`
- `data.hdf5_root: data/hdf5_chinese`
- `data.expected_feature_dim: 256`
- `model.rnn_dropout: 0.6`
- `model.input_dropout: 0.35`
- `training.checkpoint_metric: syllable_tone_per`

Train:

```bash
cd ~/nejm-brain-to-text_self
python -m chinese_speech.train_dual_stream --config chinese_speech/train_config.yaml
```

Smoke test:

```bash
cd ~/nejm-brain-to-text_self
python -m chinese_speech.train_dual_stream --config chinese_speech/train_config.yaml --num-batches 1 --output-dir chinese_speech/trained_models/smoke_best_csv --device cpu
```

Eval-only defaults to best checkpoint:

```bash
cd ~/nejm-brain-to-text_self
python -m chinese_speech.train_dual_stream --config chinese_speech/train_config.yaml --eval-only
```

Outputs:

- `checkpoints/best.pt`
- `checkpoints/latest.pt`
- `val_test_predictions.csv`
- `eval_val_test_predictions.csv` for eval-only

PER is reported as:

- `syllable_per`
- `tone_per`
- `syllable_tone_per`

## English LM Notes

The LM runtime is separate from the Mandarin work.

Recommended stable LM-on setup:

1. Start Redis:

```bash
redis-server --port 6379 --save "" --appendonly no
```

2. Start the LM server:

```bash
conda activate b2txt25_lm
cd ~/nejm-brain-to-text_self

python language_model/language-model-standalone.py \
  --lm_path language_model/pretrained_language_models/openwebtext_3gram_lm_sil \
  --redis_ip localhost \
  --redis_port 6379 \
  --gpu_number 0 \
  --nbest 100 \
  --acoustic_scale 0.325 \
  --blank_penalty 90 \
  --alpha 0.55
```

3. Run English eval with LM:

```bash
conda activate b2txt25
cd ~/nejm-brain-to-text_self/model_training

python evaluate_model.py \
  --model_path trained_models/baseline_rnn_512 \
  --data_dir ../data/hdf5_data_512 \
  --eval_type test \
  --gpu_number 0
```

Notes:

- Do not use `--nbest 1` for this path.
- Do not rely on the LM server default Redis IP; use `localhost`.
- 5gram requires `--rescore` and very large RAM, so 3gram is the practical default.

## Cleanup When Re-running English LM Eval

Safe cleanup:

```bash
rm -rf ~/nejm-brain-to-text_self/model_training/trained_models/baseline_rnn_512/eval_outputs
redis-cli -h localhost -p 6379 shutdown nosave
```

Do not delete pretrained LM assets under `language_model/pretrained_language_models/`.
Only remove `language_model/runtime/server/x86/build` and `fc_base` if you need to rebuild the native LM extension.

## Known Current Facts

- There is no separate cross-block RMS calibration step in the current repo.
- English 512D HDF5 stays separate from the Mandarin side path.
- Mandarin training is intentionally LM-off for now.
- The Mandarin dual-stream trainer chooses best checkpoint by `val_syllable_tone_per`.
